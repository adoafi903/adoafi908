# 商品一覧サイト（人気順 / おすすめ 並べ替え）

`index.html` を開くだけで動く静的サイトです。ビルド不要（HTML/CSS/JSのみ）。

## 表示内容

各作品カードに以下を1セットで表示します。

- 画像パッケージ（`images`。メイン画像＋サムネイルをクリックして切り替え可能）
- ジャンルタグ（`category`）・割引バッジ（`discountBadge`、任意）
- 作品タイトル（`title`）・価格（`price`）
- DMM/FANZA/DLsite等のアフィリエイトリンクへのCTAボタン（`affiliateUrl`）

ページ上部には広告枠（`#ad-slot-top`）があり、Google AdSense等のクリック報酬型広告タグをそのまま貼り付けられます。

## 年齢確認ゲート

初回訪問時に「18歳以上ですか？」の確認モーダルを表示し、「はい」を押すまでコンテンツを覆い隠します。確認後はブラウザの`localStorage`に記録され、再訪問時は表示されません（ブラウザ・端末ごと）。「いいえ」を選ぶと外部サイトへ遷移します。

## ジャンル絞り込み

`#genre-select` のプルダウンで以下から選べます。

- ✨ すべて表示 (ALL)
- 📖 電子書籍
- 📸 アダルト写真集
- 🎬 DL動画
- 💿 DVD

`category`フィールドの値はこの4種類（または`ALL`との組み合わせ）を想定しています。

### URLパラメータでの絞り込み（Xからの誘導用）

`?genre=` パラメータでアクセスすると、該当ジャンルが選択された状態で表示されます。

```
https://your-site.example.com/?genre=電子書籍
https://your-site.example.com/?genre=DL動画
```

X（Twitter）に投稿する際、リプライ欄に貼るURLにこのパラメータを付けておくと、該当ジャンルに絞り込んだ状態のページへ直接誘導できます（日本語部分はURLエンコードが必要な場合があります）。

## 並べ替え機能

- **人気順（👀 PV数）**: `pvCount` の降順
- **おすすめ順（🔥 売れ筋）**: `cvrScore`（クリック率×売上などから算出したスコア）の降順

`cvrScore` はこのサイト側では計算しません。DMM/DLsite等のアフィリエイト管理画面から取得したクリック数・売上データをもとに、あなたの運用ルールで算出した値を`products.json`に入れてください。

## データの入れ方（`products.json`）

```json
[
  {
    "id": "一意なID",
    "title": "作品タイトル",
    "category": "電子書籍 | アダルト写真集 | DL動画 | DVD のいずれか",
    "price": "価格の表示文字列（例: 550円（税込））",
    "discountBadge": "割引バッジの文字列（任意。不要なら省略可）",
    "affiliateUrl": "アフィリエイトのリンクURL（またはクッションページURL）",
    "pvCount": 閲覧数,
    "cvrScore": おすすめ順に使うスコア,
    "images": ["メイン画像URL", "サンプル画像URL1", "サンプル画像URL2"]
  }
]
```

- `images` / `affiliateUrl` は、各ASP（DMMアフィリエイトの公式API、DLsiteアフィリエイト等）の管理画面やAPIから取得した値をそのまま入れてください。無断スクレイピングは各サービスの利用規約違反になるため、このサイト側では取得処理を行っていません。
- `pvCount` / `cvrScore` は、各ASPの管理画面（レポート）からエクスポートした集計値を反映する運用を想定しています。現時点では自動集計は組み込んでいないため、定期的にこのファイルを更新してください。
- `category` に上記4種類以外の値を入れるとジャンル絞り込みの対象から外れます（`ALL`表示時は含まれます）。ジャンルの種類を増やす場合は`app.js`の`GENRE_LABELS`とHTMLの`<select>`の選択肢を合わせて追加してください。

## 広告タグの差し込み

`index.html` の `<div class="ad-slot" id="ad-slot-top"></div>` の中に、AdSense等の管理画面で発行された `<script>` タグをそのまま貼り付けてください。

## ローカルで確認する

```bash
cd site
python3 -m http.server 8080
# ブラウザで http://localhost:8080/index.html を開く
```

## 公開する

GitHub Pagesなど、静的ファイルをそのまま配信できるホスティングにこの`site`ディレクトリの内容をアップロードしてください。
