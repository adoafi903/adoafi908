# 商品一覧サイト（人気順 / おすすめ 並べ替え）

`index.html` を開くだけで動く静的サイトです。ビルド不要（HTML/CSS/JSのみ）。

## 表示内容

各作品カードに以下を1セットで表示します。

- 画像パッケージ（`images`。メイン画像＋サムネイルをクリックして切り替え可能）
- ジャンルタグ（`category`）・割引バッジ（`discountBadge`、任意）
- 作品タイトル（`title`）・価格（`price`）・編集部コメント（`comment`、任意）
- DMM/FANZA/DLsite等のアフィリエイトリンクへのCTAボタン（`affiliateUrl`）
- お気に入り登録用の☆ボタン（画像右上）

ページ上部には広告枠（`#ad-slot-top`）があり、Google AdSense等のクリック報酬型広告タグをそのまま貼り付けられます。

デザインは白背景・角丸なし（正方形の角）で統一しています。

## 年齢確認ゲート

初回訪問時に「18歳以上ですか？」の確認モーダルを表示し、「はい」を押すまでコンテンツを覆い隠します。確認後はブラウザの`localStorage`に記録され、再訪問時は表示されません（ブラウザ・端末ごと）。「いいえ」を選ぶと外部サイトへ遷移します。

## ジャンル絞り込み

`#genre-select` のプルダウンで以下から選べます。

- ✨ すべて表示 (ALL)
- 📖 電子書籍
- 📸 アダルト写真集
- 🎬 DL動画
- 💿 DVD

`category`フィールドの値はこの4種類（または`ALL`との組み合わせ）を想定しています。

### URLパラメータでの絞り込み（Xからの誘導用）

`?genre=` パラメータでアクセスすると、該当ジャンルが選択された状態で表示されます。

```
https://your-site.example.com/?genre=電子書籍
https://your-site.example.com/?genre=DL動画
```

X（Twitter）に投稿する際、リプライ欄に貼るURLにこのパラメータを付けておくと、該当ジャンルに絞り込んだ状態のページへ直接誘導できます（日本語部分はURLエンコードが必要な場合があります）。

## 売れ筋ランキングバナー（トップページ・自動横スクロール）

トップページ上部に、電子書籍（`category`が`電子書籍`の作品）を`cvrScore`（売上ベースのスコア）順に並べた横スクロールバナーを表示します。

- パッケージ画像のみを表示（タイトル等のテキストは表示しません）
- 自動で左方向に無限ループスクロール（`app.js`の`renderRankingBanner()`が同じ並びを2セット連結してシームレスに見せています）
- マウスホバー中は一時停止
- `prefers-reduced-motion`が有効な環境ではアニメーションを止め、手動スクロールに切り替え
- 各画像は`affiliateUrl`へのリンクになっています

対象作品が0件の場合、バナー自体を非表示にします。並び替えの基準を変えたい場合は`app.js`の`renderRankingBanner()`内のフィルタ・ソート条件を調整してください。

## コラムページ

`column.html`（記事一覧）と`column-article.html`（記事詳細）で構成される、簡易ブログ機能です。記事データは`columns.json`で管理します。

- サンプルとして10記事を用意済み（ランキングの傾向、選び方ガイド、セールの見極め方など、売れ筋・人気作品にまつわる内容）
- 各記事は`relatedProductIds`で`products.json`内の作品IDを指定すると、記事末尾に該当作品のパッケージ画像とリンクが表示されます
- トップページと同じ`.site-nav`から相互に行き来できます

### `columns.json`のフォーマット

```json
[
  {
    "id": "一意なID（文字列）",
    "title": "記事タイトル",
    "summary": "一覧ページに表示する要約文",
    "publishedAt": "公開日（表示用の文字列。例: 2026-09-01）",
    "body": ["段落1の本文", "段落2の本文", "..."],
    "relatedProductIds": ["products.jsonのid", "..."]
  }
]
```

記事を追加・編集する場合は、このファイルに項目を追加するだけで`column.html`・`column-article.html`双方に反映されます（ビルド不要）。

**注記**: 現状はJSON駆動の1ページアプリ的な構成のため、検索エンジンにはJavaScript実行後の内容として認識されます。SEOをより重視する場合は、記事ごとに静的なHTMLファイルを生成する方式への移行を検討してください。

## お気に入り・まとめて購入

- 各カード画像の右上の☆ボタンでお気に入りに登録/解除できます（`localStorage`に保存。ブラウザ・端末ごと）。
- 画面右下の「⭐ お気に入り」ボタンを押すと、お気に入り登録した作品の一覧がモーダルで開きます。
- モーダル内の各作品にはチェックボックス（初期状態はチェック済み）があり、チェックを外すことで購入対象から外せます。
- 「選択した作品をまとめて購入する」ボタンを押すと、チェックが入っている作品の`affiliateUrl`がそれぞれ新しいタブで開きます。

**注意**: DMM/DLsite等、ASPが異なる作品の代金を1回の決済にまとめることはできません（決済自体は各ASPの外部サイト側で行われるため）。ここでの「まとめて購入」は、選んだ作品の販売ページを一度にまとめて開き、購入までの手間（1件ずつ探してクリックする作業）を減らす機能です。ポップアップブロックの設定によっては、複数タブが開かない場合があるのでその場合は解除を案内してください。

## 並べ替え機能

- **人気順（👀 PV数）**: `pvCount` の降順
- **おすすめ順（🔥 売れ筋）**: `cvrScore`（クリック率×売上などから算出したスコア）の降順

`cvrScore` はこのサイト側では計算しません。DMM/DLsite等のアフィリエイト管理画面から取得したクリック数・売上データをもとに、あなたの運用ルールで算出した値を`products.json`に入れてください。

## データの入れ方（`products.json`）

```json
[
  {
    "id": "一意なID",
    "title": "作品タイトル",
    "category": "電子書籍 | アダルト写真集 | DL動画 | DVD のいずれか",
    "price": "価格の表示文字列（例: 550円（税込））",
    "discountBadge": "割引バッジの文字列（任意。不要なら省略可）",
    "comment": "編集部コメントの文字列（任意。不要なら省略可）",
    "affiliateUrl": "アフィリエイトのリンクURL（またはクッションページURL）",
    "pvCount": 閲覧数,
    "cvrScore": おすすめ順に使うスコア,
    "images": ["メイン画像URL", "サンプル画像URL1", "サンプル画像URL2"]
  }
]
```

- `images` / `affiliateUrl` は、各ASP（DMMアフィリエイトの公式API、DLsiteアフィリエイト等）の管理画面やAPIから取得した値をそのまま入れてください。無断スクレイピングは各サービスの利用規約違反になるため、このサイト側では取得処理を行っていません。
- `pvCount` / `cvrScore` は、各ASPの管理画面（レポート）からエクスポートした集計値を反映する運用を想定しています。現時点では自動集計は組み込んでいないため、定期的にこのファイルを更新してください。
- `category` に上記4種類以外の値を入れるとジャンル絞り込みの対象から外れます（`ALL`表示時は含まれます）。ジャンルの種類を増やす場合は`app.js`の`GENRE_LABELS`とHTMLの`<select>`の選択肢を合わせて追加してください。

## 広告タグの差し込み

`index.html` の `<div class="ad-slot" id="ad-slot-top"></div>` の中に、AdSense等の管理画面で発行された `<script>` タグをそのまま貼り付けてください。

## 公開する（HTTPS化 / SSL化）

`.github/workflows/deploy-pages.yml` により、このブランチの`site/`が変更されるたびに自動でGitHub Pagesへデプロイされます。GitHub Pagesは`https://`のURLを自動発行するため、追加のSSL証明書設定は不要です。

DMMアフィリエイト等の「サイトURL」申請には、発行された`https://<ユーザー名>.github.io/<リポジトリ名>/`のURLをそのまま使えます。

### 有効化に必要な、あなた自身が行う一度だけの設定

1. **リポジトリを公開(public)にする**
   `Settings > General > Danger Zone > Change repository visibility` から Public に変更。
   （GitHub Pagesは無料のFreeプランでは公開リポジトリでのみ使えます。非公開のままにしたい場合はNetlify/Vercel/Cloudflare Pages等の利用を検討してください。）
2. **GitHub Pagesのソースを「GitHub Actions」にする**
   `Settings > Pages > Build and deployment > Source` を `GitHub Actions` に設定。
3. 上記2つを設定後、このブランチの`site/`配下に変更をpushすると、自動でワークフローが実行されデプロイされます（`Actions`タブで進行状況を確認できます）。初回は`Settings > Pages`の画面、または`Actions`タブのワークフロー実行結果に表示されるURLで公開先を確認してください。
